# 名簿の整理アプリ（見本）

表記がバラバラな名簿の CSV を、ブラウザの中だけで整える見本のアプリです。

- 会社名の（株）→ 株式会社、全角・半角、空白
- 電話番号の形（090-0000-0000 など）と、消えた先頭の 0
- メールの大文字 → 小文字、形のおかしいメールに「要確認」
- 住所から都道府県を分ける
- 名前＋電話（なければメール）が同じ行に「重複」の印（消しません）

元の列は残したまま、整えた列を足して CSV（UTF-8・Excel で開けます）で保存します。

## データについて

- 入れたデータは、このブラウザの外に送りません。保存もしません（画面を閉じると消えます）
- 「見本の名簿を読む」のデータはすべて架空です（電話番号は 0000 を含む架空の番号、メールは example のドメイン）

## できないこと

- 住所の書き方の違い（「2丁目3-4」と「2-3-4」）や、会社名の言いかえが同じかは決めません。「要確認」として、最後は人が確かめます
- 固定電話の区切りは、確かな市外局番だけで決めています。それ以外は「要確認」です
